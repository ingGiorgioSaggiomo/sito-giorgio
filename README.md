# Sito professionale dell'Ing. Giorgio Saggiomo

Sito statico pubblicato con GitHub Pages: presentazione professionale, portfolio, approfondimenti tecnici, calcolatore dei compensi CTU e gioco didattico sul ponte.

## Struttura

- `index.html`: pagina principale
- `contenuti.html`: approfondimenti tecnici
- `onorari-ctu.html`: calcolatore dei compensi
- `ponte.html`: gioco didattico
- `privacy.html`: informativa privacy

Il sito non richiede una fase di compilazione: può essere aperto localmente oppure pubblicato direttamente da GitHub Pages.
